# הגדרת ההערות באתר (פעם אחת, כחמש דקות)

ההערות שנכתבות באתר נשמרות בגיליון Google של נועם, דרך סקריפט קטן (Google Apps Script). הקוד נמצא ב־`comments/Code.gs`.

## 1. הדבקת הקוד

1. פותחים את הגיליון **"אופנהיימר 128 – הערות על הממשק"** ב־Google Drive.
2. בתפריט: **Extensions → Apps Script**.
3. מוחקים את כל מה שיש בקובץ `Code.gs` ומדביקים במקומו את התוכן של `comments/Code.gs`.
4. בשורה `const ADMIN_KEY = 'CHANGE-ME';` מחליפים את `CHANGE-ME` בסיסמה שתבחרו. זו סיסמת העורך שבה תסמנו באתר סטטוס ותכתבו תשובות.
5. אם רוצים שרק מי שיודע סיסמה יוכל לקרוא את ההערות באתר, כותבים סיסמה גם ב־`READ_KEY`. אחרת משאירים ריק.
6. שומרים (Cmd+S).

## 2. פרסום כ־Web app

1. **Deploy → New deployment**.
2. ליד "Select type" לוחצים על גלגל השיניים ובוחרים **Web app**.
3. **Execute as:** Me. **Who has access:** Anyone.
4. **Deploy**. בחלון האישור: Authorize access, בוחרים את החשבון. אם מופיע "Google hasn't verified this app": Advanced → Go to … (unsafe). זה הסקריפט שלכם, והוא ניגש רק לגיליון הזה.
5. מעתיקים את ה־**Web app URL** (מסתיים ב־`/exec`).

## 3. חיבור האתר

1. ב־`docs/explorer/config.js` מדביקים את הכתובת בין המירכאות: `commentsUrl: 'https://script.google.com/macros/s/…/exec'`.
2. `git commit` ו־`git push`. אחרי דקה ההערות באתר נשמרות בגיליון.

## עבודה שוטפת

- **הבוס:** כפתור "הערה על מה שמוצג" בפינה, או הכפתור הקטן ליד חיבור, קטע, השוואה או שורה בטבלה. לא צריך חשבון.
- **נועם:** בלשונית "הערות" באתר, "מצב עורך" עם סיסמת העורך, ואז סטטוס ותשובה לכל הערה. אפשר גם לעבוד ישירות בגיליון (עמודות `status` ו־`reply`).
- **עדכון הקוד בסקריפט בעתיד:** Deploy → Manage deployments → עריכה (העיפרון) → Version: New version → Deploy. הכתובת נשארת אותה כתובת.

## פרטיות

האתר ציבורי. בלי `READ_KEY`, כל מי שיש לו את הקישור יכול לקרוא את ההערות בלשונית "הערות". סיסמת העורך נשמרת רק בסקריפט ובדפדפן של מי שהזין אותה.
